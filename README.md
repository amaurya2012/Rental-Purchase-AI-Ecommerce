# Rental and Purchase – AI-Based E-Commerce System

## Project Overview
The **Rental and Purchase – AI-Based E-Commerce System** is a full-stack web application developed to support both traditional product purchasing and time-based rental services within a single unified platform. The system is designed to address the limitations of conventional e-commerce platforms by integrating rental workflows, deposit management, and role-based access with scalable backend architecture.

This project is implemented using **Flask (Python)** and follows **industry-standard modular architecture**, making it suitable for academic evaluation as well as real-world deployment.

---

## Objectives
- To design and develop a unified e-commerce platform supporting **both purchase and rental models**
- To implement **role-based access control** for Admin, Seller, and Buyer
- To manage product inventory, rental availability, and deposits efficiently
- To provide a scalable and maintainable system architecture
- To prepare an AI-ready system for future recommendation and dynamic pricing modules

---

## System Users
### 1. Admin
- View and manage all users
- Block or activate users
- Monitor products, orders, and rentals
- View platform-wide reports

### 2. Seller
- Add products with images
- Set purchase price, rental price per day, and deposit amount
- Manage own product inventory
- View orders and rental activity related to their products

### 3. Buyer
- Register and log in securely
- Browse products
- Purchase products using cart and checkout
- Rent products for a selected duration
- View order history and rental history
- Return rented products

---

## Key Features
- Dual transaction model: **Purchase + Rental**
- Secure authentication using Flask-Login
- Role-based dashboards (Admin / Seller / Buyer)
- Product image upload and management
- Cart and checkout system
- Rental booking with date validation
- Deposit handling for rentals
- Rental return workflow
- Admin analytics and monitoring
- Clean UI with responsive design
- AI-ready interaction logging
